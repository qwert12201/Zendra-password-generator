Hello, this is password-generator with UI and multithread generation

## Features
1. MultiThread generation
2. Options
3. Copy button and save file button
4. Language change
5. Hashes

## Installation
0. You need to install Python >= 3.5 and pip
1. Download repository
2. Extract files to some directory
3. Open terminal (**cmd.exe**)
4. Go to project directory: `cd path_to_project`
5. Run package installer: `pip install -r requirements.txt`
6. Run main file: `python main.py`

Thanks for installation, if you find bugs, please report them to "Issues" from Github
